# Chrono (legacy promises)

Rainmeter **Chrono** promised a desktop **clock collection** with multiple visual styles.

## Promised behavior

- Live clock and date
- 12/24-hour and seconds toggles
- Multiple StyleCatalog / skin chrome variants
- Desktop widget chrome (drag, align, Z-order, unload via shared Ctx)

## Host today

Native Chrono widget via `TileRuntime`. See parity `tile_chrono_mvp`. Install stub: [`Tiles/Chrono`](../../Tiles/Chrono).
