# Inlay (legacy promises)

Rainmeter **Inlay** promised a customizable **Start menu replacement**.

## Promised behavior

- Pinned apps / shortcuts and module shortcuts
- Search / launch targets
- Interchangeable modules and appearance themes
- Hotkey to open the launcher
- Optional volume-hook accessories (Rainmeter `Plugin=Tessera`)

## Host today

Native Inlay overlay MVP (pins + search). See parity `tile_inlay_mvp`. Install stub: [`Tiles/Inlay`](../../Tiles/Inlay).
