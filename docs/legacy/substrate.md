# Substrate (legacy promises)

Rainmeter **Substrate** (formerly MIUI Shade) promised a PC **control-center / notification shade**.

## Promised behavior

- Slide-down / hotkey shade with quick toggles
- Mute, volume, brightness, and related system controls
- Integrated media controls
- Extra modules (e.g. weather status)
- Appearance presets (Dark/Light), blur/acrylic, scale and animation options

## Host today

Native Substrate overlay MVP (mute / volume / brightness). See parity `tile_substrate_mvp`. Install stub: [`Tiles/Substrate`](../../Tiles/Substrate).
